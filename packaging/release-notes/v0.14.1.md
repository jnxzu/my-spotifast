Spotifast J 0.14.1 adds a Windows launcher that updates the installed copy from the local source checkout.

- Compare Cargo.toml's package version with the installed executable before launch. Build only if the repository version is higher; equal or lower versions skip the build.
- Build the local source in release mode, verify the resulting version and checksum, and replace the installed binary atomically with a rollback copy.
- A failed build, stale artifact or changing repository version leaves the installed copy usable. An already running app defers the update.
- Start menu shortcuts and this installation's Spotify links use the launcher. Source is assumed current; no Git fetch, pull or release download runs.
- Local setup disables automatic GitHub release checks for this installation. Builds use the installed Rust/C++ tools and cached dependencies without network access.

The sidebar, other application settings, sign-ins, data paths and installed identity are preserved.
