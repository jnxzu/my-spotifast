Spotifast J 0.14.0 brings selected upstream improvements into the personal fork while keeping its pins-only sidebar, connection controls, quota handling and cached-playlist protections.

- Home's New releases opens a songs-only list with bulk selection, queue, Like and playlist actions. It reads up to 50 releases without marking Spotify's notification feed as seen; the Web API fallback covers up to 50 followed artists.
- Recent listening supplies Home's quick-access tiles. Your top mixes joins Made for you through the existing session cache and cooldown.
- Podcast pages can refresh from their More menu, and header artwork can be enlarged with a click.
- Named equalizer presets save the preamp and ten bands and are available in Settings and the mini player.
- Repeat mode persists across restarts. Play next supports local playback, and search-song playback starts the selected song alone.
- Repeated playlist songs start and highlight the selected occurrence when confirmed positions are available. Removal requires a complete confirmed list and refuses repeated songs; use Spotify to delete one occurrence. The pinned playback dependency does not support that write safely.
- Liked Songs reconciles cross-device re-likes, temporary lyrics rate limits receive bounded retries, liked-heart menus expose playlist actions, mini-player slider hit areas are more precise, tiny restored windows recover, and empty recommendations finish loading.

The application and executable identity, protected sign-in storage, updater destination and dependency revisions are unchanged. These are source changes for the fork; this note does not announce a published installer or an update to an installed copy.
